 Estructura del Proyecto
- Producto.java → Clase nodo del árbol
- ArbolInventario.java → Lógica del árbol binario
- Main.java → Menú e interacción con el usuario

Instrucciones de Ejecución
1. Abrir un compilador Java en línea (OnlineGDB).
2. Copiar el contenido de los archivos `.java`.
3. Ejecutar el programa.
4. Utilizar el menú para registrar, listar y buscar productos.
